The MPAI Catalog

Metadata Packet for AI Indexing · 17 packets · updated 2026-06-08

Entity-level inscription packets for the composition layer.

A Metadata Packet for AI Indexing (MPAI) is a structured, DOI-anchored disambiguation deposit that inscribes a specific entity, framework, or term into the retrieval substrate so the composition layer renders it correctly. MPAIs are how authors stop being summarized wrong.

The discipline emerged inside the Semantic Economy research program as the operational answer to provenance erasure: rather than rely on the platform to attribute correctly, the producer deposits an inscription packet that specifies how the entity is to be indexed and anchors that specification at a permanent DOI. Each packet carries a tooth (the single sentence the substrate must preserve), a description (the longer specification), a subject identifier (what is being disambiguated), and a date.

The catalog below indexes packets that follow the MPAI grammar — either through strict-label deposits (EA-MPAI-*, MPAI-*, or titles containing “Metadata Packet for AI Indexing”) or through structural compliance with the discipline's operational requirements. New packets join the catalog via GitHub submission.

How to deposit an MPAI

1. Compose a packet following the MPAI grammar: a code (e.g. EA-MPAI-X-01), a version, a tooth (single load-bearing sentence), a description, a subject identifier, and a citation graph of related deposits.

2. Deposit on Alexanarch (or any DOI-issuing repository) with the MPAI label in the title.

3. Submit to the catalog via GitHub Issue or open a pull request adding the entry to public/catalog.json.
