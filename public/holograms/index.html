Framework holograms

A framework hologram holds a framework in two components, deposited as one record: the map, which a person reads, and the holographic kernel, which a machine can rebuild and test against the records it points to. The specification is EA-HK-FRAME-01 (#1753). Each hologram's readings by machine readers, its reconstructions and evaluations, are kept in the mantle-bearing dataset, the archive's table for inspection and evaluation. 5 holograms, newest first.
